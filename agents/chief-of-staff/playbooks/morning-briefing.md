# Playbook: morning briefing

When: asked for the briefing, or on the morning schedule.

Steps:
1. Run the route-incoming playbook first so nothing new is missed.
2. Read `board/board.md`, `approvals/pending/`, and the newest file in each `agents/<name>/work/`.
3. Check dates. If an employee's source data is older than 7 days, say so and name the file date.
4. Write `agents/chief-of-staff/work/briefing_<date>.md` in the order given in job.md (risks and blockers, decisions, written-confirmation gaps, approvals, employee activity, stale data).
5. Keep it to one page. Lead with the top three risks. Everything else is bullets.
6. Report to Lori in the chat: top three risks, decisions needed, path to the file.

Done when: file saved, every claim has a source and a date, nothing sent externally.
