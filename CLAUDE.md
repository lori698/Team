# AI Team — Operating System

This folder is a team of AI employees. Claude Code is the engine; this structure is what makes it a team.

## Layout

| Path | Purpose |
|---|---|
| `company/` | Shared knowledge every employee reads first: `owner.md`, `voice.md`, `roster.md`, `rules.md` (shared memory) |
| `agents/<name>/` | One workspace per employee: `job.md`, `playbooks/`, `notebook.md`, `work/` |
| `.claude/agents/<name>.md` | Claude Code subagent definition for each employee (generated by `scripts/new-agent.ps1`) |
| `board/board.md` | Central To Do / Doing / Done board |
| `handoffs/<name>/` | Inbox per employee. Drop a message file here to pass work on |
| `approvals/` | Requests waiting for a human decision (`pending/`, `approved/`, `rejected/`) |
| `schedules/schedules.json` | Which agent runs when |
| `scripts/` | Create employees, hand off work, run agents, register schedules |

## Every employee, at the start of every task

1. Read `company/owner.md`, `company/voice.md`, `company/roster.md`, `company/rules.md`.
2. Read own `agents/<name>/job.md` and `notebook.md`.
3. Check own `handoffs/<name>/` for new messages and `board/board.md` for assigned tasks.
4. Use the matching playbook in `agents/<name>/playbooks/` if one exists.

## Every employee, at the end of every task

- Move the task on the board (To Do -> Doing -> Done) with a one-line result.
- Record any lesson in own `notebook.md`. If it applies to everyone, add it to `company/rules.md` instead.
- If the work belongs to another role, hand it off with `scripts/handoff.ps1`; don't do it yourself.

## Hard safeguards (apply to everyone)

Never do these without a file in `approvals/approved/` that names the exact action:

- Send any external communication (email, message, post, comment).
- Spend money or start anything billable.
- Delete or overwrite data outside your own `agents/<name>/work/`.
- Touch credentials or anything under `.secrets/`.

To request approval: create a file in `approvals/pending/` using `approvals/TEMPLATE.md`, then stop and report. Draft, don't send.

Each employee may only write inside its own `agents/<name>/`, `handoffs/`, `board/`, `approvals/pending/`. Changes to `company/` are made by the owner or via a proposal to the chief-of-staff.
